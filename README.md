# رحلة الحاجات والرغبات

تطبيق لعبة تعليمية يعمل مباشرة من المتصفح على الهاتف والكمبيوتر. لا يحتاج Python أو pygame أو تثبيتًا محليًا.

## التشغيل المحلي

```bash
python3 -m http.server 3000
```

ثم افتح `http://localhost:3000`.

## محتويات المشروع

- `index.html`: الصفحة الرئيسية.
- `styles.css`: التصميم المتجاوب ورسومات الشخصية.
- `app.js`: منطق اللغة والمراحل والنقاط والأصوات التفاعلية.
- `manus-routes.json`: بيان مسارات التطبيق.
- `public/manus-routes.json`: نسخة المسارات للمضيف.
- `TODO.md`: المتطلبات المعتمدة.

الأصوات تُنشأ مباشرة عبر Web Audio API، لذلك لا توجد ملفات صوت خارجية أو رموز تعبيرية تسبب مربعات. زر اللغة يبدل العربية والإنجليزية، والمراحل الثلاث تعمل باللمس أو الماوس.

## النشر على GitHub Pages

المشروع مجهز ليعمل كصفحة ثابتة. بعد رفعه إلى GitHub، يمكن تفعيل Pages من Settings ثم Pages واختيار GitHub Actions، أو استخدام ملف النشر الموجود في `.github/workflows/pages.yml`.
